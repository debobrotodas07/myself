# 🎬 Cinematic Scroll Portfolio

Welcome to my personal portfolio website! This is a highly animated, smooth-scrolling website designed to showcase my work with a modern, cinematic feel. 

## 🚀 Live Demo
You can view the live website here: **[https://deobrotodas07.github.io/myself/portfolio.html](https://deobrotodas07.github.io/myself/portfolio.html)**

## ✨ Features
- **Lenis Smooth Scrolling:** Buttery-smooth page transitions.
- **GSAP ScrollTrigger:** Animations that trigger and scrub as you scroll.
- **Parallax Effects:** Background and foreground elements move at different speeds to create depth.
- **Staggered Text Reveals:** Headings and text elegantly fade in.
- **Sticky Card Stacks:** Project cards stack and scale beautifully on scroll.

## 🛠️ Built With
- HTML5 & CSS3
- Vanilla JavaScript
- [GSAP (GreenSock)](https://greensock.com/gsap/)
- [Lenis](https://lenis.studiofreight.com/)
- Built with the help of AI (ChatGPT / Codex Agent)

## 💻 How to View Locally
Since this is a standalone HTML file, no build tools or servers are required!
1. Download or clone this repository.
2. Open `portfolio.html` in any web browser (Chrome, Safari, Firefox).
3. Scroll down to see the animations in action.
